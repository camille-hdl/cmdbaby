# 17: Finaliser le parcours parent accessible

**What to build:** Le parent peut comprendre l’état de BabyWork, configurer le fond, corriger les permissions, démarrer et récupérer une session au sein d’un parcours cohérent et accessible.

**Blocked by:** 06 — Guider le parent dans les permissions; 08 — Conserver le dossier et les réglages; 13 — Ajouter la sortie adulte de secours.

**Status:** ready-for-agent

- [ ] L’écran principal distingue clairement configuration prête, permissions manquantes, source invalide, session active et récupération nécessaire.
- [ ] Le chemin de configuration jusqu’au démarrage évite les actions disponibles mais vouées à échouer.
- [ ] Les messages expliquent une cause et une action corrective sans jargon système inutile.
- [ ] Tous les contrôles de l’interface parent sont utilisables au clavier avec un ordre de focus cohérent.
- [ ] Les libellés, rôles, valeurs et annonces nécessaires aux technologies d’assistance sont présents.
- [ ] La procédure des deux sorties adultes et les limites du confinement sont visibles avant le démarrage.
- [ ] Des tests d’interface couvrent le premier lancement, l’autorisation refusée, le choix du fond, le démarrage, la sortie et la récupération.
