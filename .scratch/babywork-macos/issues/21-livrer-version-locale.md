# 21: Livrer une version locale signée

**What to build:** Le propriétaire peut installer, autoriser, utiliser et récupérer une version Release signée de BabyWork sur son Mac à partir d’une procédure reproductible.

**Blocked by:** 20 — Exécuter la matrice d’acceptation macOS.

**Status:** ready-for-agent

- [ ] Un build Release utilise l’identité stable validée et le Hardened Runtime avec les seuls droits nécessaires.
- [ ] La procédure de construction et d’installation produit le même type d’artefact à partir d’un environnement documenté.
- [ ] Le guide de première utilisation explique les permissions, le choix du dossier, le démarrage et les deux sorties adultes.
- [ ] Une procédure de récupération couvre permission refusée ou révoquée, source d’images absente et session interrompue.
- [ ] Les limites confirmées par la matrice d’acceptation sont visibles dans la documentation utilisateur.
- [ ] La recommandation d’un compte macOS standard dédié à l’enfant est présentée comme protection complémentaire et non comme fonction de l’application.
- [ ] Une installation propre puis une mise à niveau depuis une version de réglages antérieure sont vérifiées.
- [ ] La livraison n’ajoute ni télémétrie, ni accès réseau, ni exécution privilégiée.
