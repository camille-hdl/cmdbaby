# Labels de triage

Les skills raisonnent en fonction de cinq rôles de triage canoniques. Ce fichier associe chaque rôle au label effectivement utilisé dans le suivi des demandes de ce dépôt.

| Label dans mattpocock/skills | Label dans notre suivi | Signification                                        |
| ---------------------------- | ---------------------- | ---------------------------------------------------- |
| `needs-triage`               | `needs-triage`         | La demande doit être évaluée par une personne responsable |
| `needs-info`                 | `needs-info`           | En attente d’informations complémentaires de l’auteur |
| `ready-for-agent`            | `ready-for-agent`      | Entièrement spécifiée, prête pour un agent autonome   |
| `ready-for-human`            | `ready-for-human`      | Nécessite une implémentation humaine                  |
| `wontfix`                    | `wontfix`              | Ne sera pas traitée                                   |

Lorsqu’un skill mentionne un rôle (par exemple « appliquer le label de triage prêt pour un agent »), utiliser le label correspondant dans ce tableau.

Modifier la colonne de droite pour l’adapter au vocabulaire réellement utilisé.
